# Module 3 images

No user photographs were available when this module was implemented.
`synthetic_edges.png` and `synthetic_texture.png` are generated test patterns,
not photographs. `checkerboard.png` is also generated.

Add two actual photographs, for example `photo_01.jpg` and `photo_02.jpg`, then run
`python run_experiments.py --photos photo_01.jpg photo_02.jpg` from `module3/`.
The originals remain unchanged; processed arrays have maximum dimension 512.
